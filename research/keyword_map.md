# 대구 지역 키워드 맵 — 치킨 체류형 관광

주제: 치킨의 수도, 더 오래 머무는 도시로 — 대구 치킨 관광자원으로 체류시간을 늘리는 상품 기획
렌즈: 이 키워드가 **치킨에서 시작해 저녁 · 야간 · 숙박까지 머물게 하는 데** 쓰일 수 있는가

출처 표기
- `팀 지식 (중간 발표)` — 10/30 중간 발표자료에 원출처와 함께 실린 내용. 노트 작성 때 원출처를 다시 열어 확인
- `팀 지식` — 팀이 알고 있으나 아직 출처를 찾지 않은 것
- `검색 필요` — 후보만 적어 둔 것. Claude Code 웹 검색으로 채운다
